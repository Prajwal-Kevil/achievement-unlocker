# Current GitHub achievements

This guide documents the achievement types that are commonly earnable through normal GitHub activity. Requirements can change, and GitHub controls the final award decision.

| Achievement | Legitimate path |
| --- | --- |
| Quickdraw | Close an issue or pull request within five minutes of opening it. |
| Pull Shark | Merge pull requests; higher tiers require more merged pull requests. |
| YOLO | Merge your own pull request without a code review. |
| Pair Extraordinaire | Have a genuine co-author on a commit that lands in a merged pull request. |
| Galaxy Brain | Provide accepted answers in GitHub Discussions. |
| Starstruck | Build a repository that receives substantial community interest and stars. |
| Public Sponsor | Sponsor open-source work through GitHub Sponsors. |

Some historical badges are no longer normally earnable. Do not use spam, fake accounts, artificial stars, fabricated co-authorship, or unauthorized activity to pursue achievements. Useful contributions and respectful community participation matter more than the badge.
